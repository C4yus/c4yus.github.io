# Pacotes de skills para carregar na conta Claude

Cada .zip é uma skill (uma pasta com SKILL.md). Para funcionarem em todo o lado (PC do trabalho, casa, nuvem, telemóvel):
claude.ai → Settings → Capabilities → Skills → carregar o .zip (um de cada vez).

Gerados a partir de `.claude/skills/` a 22 nov 2026. Se uma skill mudar, voltar a gerar o .zip e carregar de novo.
Todas cumprem a regra: nenhuma envia dados para fora (ver `regras-skills-cayus`).
